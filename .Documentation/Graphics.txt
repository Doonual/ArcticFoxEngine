Graphics contains all the logic for showing a texture to the screen.
It contains:
		- Render form
		- Swapchain
		- Render target
		- Depth stencil
		- Command objects
It does not handle any rendering tasks, instead rendering tasks should write to the render target view


Setup
Graphics is setup by running Graphics.Init()
	1.	Attach the graphics device
	2.	Setup the command lists and synchronisation
	3.	Setup the swapchain
		Setting up the swapchain also creates the render targets and depth stencil resources

Usage
	Showing the render target to the screen
	1.	Write whatever to the render target
	2.	Call Buffer()
		Waits for the command list to finish being executed
		Presents the current render target to the screen
		Swaps which render target to write to

	Compiling shaders
	1. Call CompileShader()

	Waiting for command list to finish
	1. Call WaitForCmdList()
