A descriptor is a small object that describes a resource. Also known as a view
Descriptors are grouped together to form a descriptor table.

Descriptors can take the form of...
- Constant buffer views (CBVs)
- Unordered access views (UAVs)
- Shader resource views (SRVs)
- Samplers

A descriptor for a constant buffer view represents a reference to only 1 element in a constant buffer
